# Android Client

## 역할
- NotificationListenerService 기반 알림 감지
- 알림 접근 권한 처리
- 원본 알림 이벤트 생성
- Spring Boot API 전송
- 거래/피드백 조회 UI

## 첫 번째 개발 목표
1. 빈 Android 프로젝트 생성
2. NotificationListenerService 등록
3. 실제 기기에서 알림의 packageName/title/text를 Logcat에 출력
4. 서버로 원본 알림 전송

Android Studio 프로젝트가 생성되면 이 디렉터리의 안내 문서는 실제 프로젝트 파일로 대체/확장한다.
