# Spring Boot Backend

## 역할
- Android에서 전달된 원본 알림 수신
- 금융 앱별 알림 해석 및 정규화
- 거래 정합성 처리
- 거래 상태 관리
- 사용자 정의 규칙 평가
- 거래/규칙/피드백 REST API 제공

## 첫 번째 개발 목표
1. Spring Boot 프로젝트 생성
2. `GET /health` 또는 동등한 health check 구현
3. 원본 알림 수신 API 구현
4. Android에서 전달된 이벤트 로그 확인

Spring Boot 프로젝트가 생성되면 이 디렉터리의 안내 문서는 실제 프로젝트 파일로 대체/확장한다.
