# 주 단위 개발 계획

목표: **2026년 10월 31일까지 Release Candidate 수준의 동작 가능한 Android 앱 완성**

## 9/24 ~ 9/29 — 개발 기반
- GitHub 저장소 구성
- Android 프로젝트 생성 및 실기기 실행
- NotificationListenerService PoC
- Room 기반 Raw Notification 저장 계층 구현
- 실기기에서 알림 저장 / 중복 행 / 재실행 후 데이터 유지 확인
- Spring Boot 통신 가능성 PoC 수행 후 MVP에서는 서버 연결을 보류

**완료 기준**
> 실제 Android 알림이 감지되고 원본 데이터가 Room에 지속적으로 저장된다.

## 9/30 ~ 10/6 — 첫 금융 알림 정규화
- 문서를 Android 로컬 처리 구조로 정리
- 실제 금융 알림 샘플 확보
- 금융 알림 후보 선별 정책 구현
- null / 무의미 알림 처리 정책 정리
- 필요 시 bigText / subText 등 원본 필드 보강
- `NormalizedFinancialEvent` 모델 정의
- 첫 금융 앱/결제수단 Parser 구현
- 정규화 결과 저장 또는 개발용 조회 화면 구현
- 실제 기기에서 정규화 결과 검증

**발표 데모**
> 실제 금융 알림 → Room 원본 저장 → 금액/가맹점/거래 유형 등 표준 이벤트 변환

- 두 번째 이상의 금융 알림 형식 지원

- 정규화 결과 조회 UI 보강

**발표 데모**

## 10/14 ~ 10/20 — 거래 정합성
- Transaction 모델과 상태 정의
- 동일 실제 거래의 다중 알림 / 중복 후보 판별

- 환불/거래 상태 모델 구현

- 주요 예외 상황 처리
- Android 권한/오류 UX 정리
- 개인정보 최소수집 및 로그 점검
- 핵심 테스트 보강

**최종 완료 기준**
> 금융 알림 수집 → Room 저장 → 정규화 → 정합성 처리 → 거래 저장 → 규칙 평가 → 가계부/피드백이 실제 기기에서 끝까지 동작한다.

## 개발 원칙
- 월요일에는 신규 기능 추가를 멈추고 테스트와 발표 준비에 집중한다.
- 핵심 흐름을 깨뜨리는 기능 확장은 다음 버전으로 미룬다.
- AI, 오픈뱅킹, 결제/광고, iOS, 클라우드 동기화는 10월 MVP 범위에 포함하지 않는다.
- 백엔드가 없어도 MVP 핵심 기능이 완결되어야 한다.
