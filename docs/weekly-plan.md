## 개발 원칙

- 월요일에는 신규 기능 추가를 멈추고 테스트와 발표 준비에 집중한다.
- 핵심 흐름을 깨뜨리는 기능 확장은 다음 버전으로 미룬다.
- AI, 오픈뱅킹, 결제/광고, iOS, 클라우드 동기화는 10월 MVP 범위에 포함하지 않는다.
- 백엔드가 없어도 MVP 핵심 기능이 완결되어야 한다.
