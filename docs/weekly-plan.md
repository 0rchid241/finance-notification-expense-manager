# 주 단위 개발 계획

- 추가 금융 앱/알림 유형 지원

- 가맹점·금액·거래 유형 처리 개선

**발표 데모**

## 10/14 ~ 10/20 — 거래 정합성
- 중복 거래 후보 판별

- 정합성 테스트 작성

**발표 데모**

- 사용자 규칙 모델 구현

## 10/28 ~ 10/31 — 안정화
- 주요 예외 상황 처리
- Android 권한/오류 UX 정리
- 핵심 테스트 보강
- Release APK/AAB 빌드
- README 및 설계 문서 정리
- 최종 데모 시나리오 제작

**최종 완료 기준**
> 금융 알림 수집 → 정규화 → 정합성 처리 → 거래 저장 → 규칙 평가 → 가계부/피드백이 실제 기기에서 끝까지 동작한다.

## 개발 원칙
- 월요일에는 신규 기능 추가를 멈추고 테스트와 발표 준비에 집중한다.
- 핵심 흐름을 깨뜨리는 기능 확장은 다음 버전으로 미룬다.
- AI, 오픈뱅킹, 결제/광고, iOS는 10월 MVP 범위에 포함하지 않는다.
