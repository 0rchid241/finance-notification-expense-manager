# 요구사항 — 2026년 10월 MVP 기준

> **기준일: 2026-11-03 · 개발 상태: MVP 개발 완료**  
> 이 문서는 9~10월의 초기 제안서가 아닌 **실제 완성한 MVP의 수용 범위**를 기록합니다. 초기의 더 넓은 목표와 후속 후보는 [로드맵](ROADMAP.md)에 구분해 두었습니다.

## 1. 문제와 MVP 범위

사용자가 금융 앱의 거래 알림을 통해 자동 기록된 지출을 조회하고, 잘못 인식되거나 중복·환불이 의심되는 거래를 직접 검토할 수 있도록 합니다.

- **플랫폼:** Android 7.0(API 24) 이상
- **지원 입력:** 카카오뱅크의 확인된 입금·출금 알림, 삼성 월렛의 확인된 결제 완료 알림, 수동 입력 거래
- **저장·처리:** 기기 내부 Room DB. 백엔드·로그인·인터넷은 핵심 기능에 필요하지 않음
- **완료의 의미:** 정의한 주요 기능의 구현 및 일부 자동 테스트·실기기 검증 기록 보유. 스토어 출시 또는 모든 실거래 상황 검증을 의미하지 않음

## 2. 기능 요구사항 — 현재 MVP

| 번호 | 요구사항 | 현황 |
| --- | --- | --- |
| F-01 | 사용자가 알림 접근 권한 상태를 확인하고 Android 설정으로 이동할 수 있어야 한다 | **구현** |
| F-02 | 허용된 금융 앱 패키지의 원본 알림을 Room에 먼저 저장할 수 있어야 한다 | **구현** |
| F-03 | 지원하는 알림 형식을 공통 금융 거래 데이터로 변환해야 한다 | **구현 (확인된 형식 한정)** |
| F-04 | 알 수 없는 형식을 정상 거래로 만들지 않고 실패 상태를 남겨야 한다 | **구현** |
| F-05 | 거래가 아닌 포인트 적립 알림을 거래 생성 없이 제외할 수 있어야 한다 | **구현 (삼성 월렛 확인 형식)** |
| F-06 | 사용자가 월별·유형별 거래를 조회하고 수동 추가·수정·삭제할 수 있어야 한다 | **구현** |
| F-07 | 중복·내부이체·환불 의심 관계를 후보로 표시하고 확정·거절할 수 있어야 한다 | **구현 (사용자 검토형)** |
| F-08 | 확정된 중복·환불 관계를 월간 순지출 계산에 반영해야 한다 | **구현 (정의된 집계 범위)** |
| F-09 | 출금 금액 및 상대방 키워드 규칙을 저장하고 거래에 적용해야 한다 | **구현 (2종)** |
| F-10 | 홈·거래·규칙·설정 화면과 다크 모드를 제공해야 한다 | **구현** |

**F-07의 의미:** 의심 거래를 자동 병합·삭제하거나 실제 취소·환불 사실을 확정하는 것이 아닙니다. 사용자 검토 결과에 따라 일부 집계 보정이 적용됩니다.

## 3. 데이터와 안정성 요구사항

- 원본 알림에는 패키지명·알림 키·제목·본문·시각·처리 상태를 보존합니다.
- Raw 상태는 `PENDING`, `PROCESSED`, `PARSE_FAILED`, `IGNORED`를 구분합니다.
- 해석 후 거래·정합성 후보·규칙 결과·원본 상태 변경은 Room 트랜잭션으로 처리합니다. 원본 최초 저장은 이에 앞서 수행합니다.
- 수동 거래에는 원본 알림을 만들어 연결하지 않습니다.
- 거래 수정/삭제가 원본 알림 자체를 바꾸거나 삭제하지 않도록 합니다.
- DB 변경은 명시적 Room Migration으로 기존 데이터를 보존하도록 설계했습니다(현재 v6).
- 금융 알림의 제목·본문 등 민감한 내용을 일반 앱 로그에 출력하지 않도록 처리합니다.
- Parser·거래 계산·DB 저장은 자동 테스트 가능한 단위로 분리합니다.

**경계:** 완전한 무손실 수집, 암호화 저장, 모든 버전에서의 무결점 Migration, 전체 기기 호환성을 보증하지 않습니다.

## 4. 테스트/수용 확인

- **자동 검증:** Parser/DB/정합성/규칙/집계 단위 테스트, 일부 Android 계측/Compose UI 테스트
- **실기기 확인:** 카카오뱅크 입출금의 수집·저장·화면 표시, 삼성 월렛 실제 알림 형식 관련 검증
- **CI:** GitHub Actions에서 단위 테스트 및 `debug`·`externalDebug` APK 빌드
- **기록:** [PR #10](https://github.com/0rchid241/finance-notification-expense-manager/pull/10), [PR #14](https://github.com/0rchid241/finance-notification-expense-manager/pull/14), [Actions](https://github.com/0rchid241/finance-notification-expense-manager/actions)

테스트 수치는 기록된 실행 시점의 결과이며 앱의 모든 실제 거래 시나리오 검증을 의미하지 않습니다.

## 5. MVP에서 제외한 기능

- 카카오뱅크·삼성 월렛 외 다른 금융사 및 모든 알림 형식 지원
- 승인 취소·부분 환불·출처 간 중복 거래의 완전 자동 해석과 멱등 보장
- 누적 기간·카테고리·횟수 기반 규칙, 알림 배너/푸시를 통한 외부 피드백
- 실패 Raw 사용자 조회·재처리 기능
- iOS, 오픈뱅킹, 로그인, 다중 기기 동기화, 클라우드 백업, AI/ML 분석
- 상용 Release 서명, Google Play 정식 출시 및 운영
